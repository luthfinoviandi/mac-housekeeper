# MacHousekeeper project steering

This folder contains rules that are specific to MacHousekeeper. Portable rules belong in `.ai-steering/`; current system facts belong in a future system-map location; product and engineering deliverables belong in `docs/`.

## Files

| File | Read before |
|---|---|
| [stack.md](stack.md) | choosing libraries, structuring Swift code, or changing the build target |
| [security.md](security.md) | scanning, deleting, moving, or reporting on user files; invoking subprocesses; handling permissions |
| [workflows/requirement-definition.md](workflows/requirement-definition.md) | defining or revising requirements |
| [workflows/design-document.md](workflows/design-document.md) | writing an architecture approach, technical design, or implementation plan |

The lead architect approved the initial project steering setup on 2026-10-15.
